 Project Overview

EWU Campus Wallet is a banking-inspired Smart Campus application that provides a centralized digital wallet for East West University. The platform allows students to add money, pay semester fees, settle library and disciplinary fines, make QR-based campus shop payments, and use a Pay Later feature for eligible purchases.

The system includes five dedicated role-based dashboards for Students, Admin Office, Library, Accounts Office, and Campus Shops, enabling each department to efficiently manage financial operations through a unified platform.

Built with a modern fintech-inspired interface, the application delivers a secure, fast, and user-friendly digital payment experience across the university.
